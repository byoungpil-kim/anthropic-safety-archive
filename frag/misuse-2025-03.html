02 · 다룬 위해 영역

네 개의 사례 영역

03 · 보고서가 제시한 추세

두 가지 교훈

  • 이용자들이 프런티어 모델로 다수의 소셜미디어 봇이 얽힌 복잡한 남용 시스템을 "준자율적으로 오케스트레이션"하기 시작했고, 에이전틱 AI가 발전할수록 이 경향이 이어질 것으로 예상했다. 게시 페이지
  • 생성형 AI는 덜 숙련된 행위자의 역량 개발을 가속해, 과거 기술적으로 숙련된 사람만 가능했던 수준으로 활동하게 할 수 있다. 게시 페이지

PDF는 영향력 공작이 콘텐츠 중심에서 관계 중심으로 옮겨가고 있으며, 바이럴 순간을 재는 기존 Breakout Scale에 더해 관계 형성과 공동체 편입을 평가하는 새 틀이 필요하다고 적었다. PDF p.3

04 · 사례별 요약

4건

다중 고객 영향력 네트워크 운영영향력

금전 동기의 "영향력 공작 서비스" 사업자가 X와 Facebook에서 100개 넘는 페르소나를 운용하며 수만 개의 실제 계정과 교류했다. 같은 인프라로 최소 4개 고객 캠페인을 돌렸다(유럽 청중 대상 에너지 안보 서사, 이란 청중 대상 문화 정체성 서사, EU 규제를 비판하며 UAE를 기업 환경으로 홍보, 유럽 한 국가의 알바니아계 인사 지지, 케냐 개발 사업과 정치인 홍보). Anthropic은 국가 연계 캠페인에서 예상되는 서사와 일치하지만 어느 국가에도 귀속을 확인하지 않았다고 밝혔다. PDF pp.1–2

Claude 역할
각 페르소나가 특정 게시물에 좋아요·공유·댓글·무시 중 무엇을 할지 고객의 정치 목표에 따라 결정, 페르소나별 정치 성향 지침 유지, 모국어 응답 생성, 이미지 생성 모델용 프롬프트 작성과 결과 평가. JSON 기반 페르소나 관리
도달
Breakout Scale 1단계, 바이럴 콘텐츠 없음. 대신 장기적 관계 유지에 집중 PDF p.3
IoT 보안카메라 유출 크리덴셜 수집사이버

상용 유출 데이터 플랫폼과 인포스틸러 로그 텔레그램 커뮤니티를 결합한 숙련 행위자가 오픈소스 스크래핑 도구 재작성, 표적 URL 수집 스크립트, 스틸러 로그 게시물 처리 시스템, 검색 기능 개선에 Claude를 썼다. 개별 기법은 이중용도지만 전체 맥락상 무단 접근 목적이었다. 실제 배포 성공은 확인되지 않았다. 게시 페이지

채용 사기의 실시간 문장 세탁사기

정당한 기업의 채용 담당자를 사칭해 동유럽 구직자를 노린 사기범들이 서툰 비원어민 영어를 "원어민이 쓴 것처럼" 고쳐 달라고 요청하고, 채용 서사·면접 질문·메시지 서식을 다듬었다. 성공한 사기 사례는 확인되지 않았다. 게시 페이지

초보 행위자의 멀웨어 개발사이버

정규 코딩 능력이 거의 없는 행위자의 도구가 기본 기능에서 얼굴 인식과 다크웹 검색을 갖춘 고급 도구 모음으로, 단순 배치 스크립트 생성기에서 탐지 회피형 악성 페이로드를 만드는 GUI 빌더로 발전했다. 실제 배포는 확인되지 않았다. 게시 페이지

05 · AI 관여 수준

준자율 오케스트레이션

영향력 공작 사례에서 Claude는 봇 계정의 행동을 결정하는 "오케스트레이터"로 쓰였고, PDF는 "AI가 교류에 관한 전략적·전술적 결정을 모두 내린다"고 표현했다. PDF pp.1, 3 나머지 3건은 코드·문장 작성을 돕는 보조적 사용이었다. 작업 비중 같은 수치는 제시되지 않았다.

06 · 안전장치 성과와 실패

거부·우회에 관한 서술 없음

네 사례 모두 모델이 요청을 거부했는지, 어떤 방식으로 우회되었는지에 대한 서술이 없다. 영향력 공작 봇에는 "봇이냐"는 질문에 유머와 비꼼으로 답하고, 시나 레시피를 요구해 캐릭터를 깨려는 시도를 버티라는 지시가 들어 있었다. PDF p.2 나머지 3건은 모두 "실제 성공이나 배포를 확인하지 못했다"고 적었다.

07 · 탐지 방법과 대응 조치

Clio와 계층적 요약

  • 위협 인텔리전스 프로그램을 표준 대규모 탐지가 놓친 위해를 잡는 "안전망"으로 규정 게시 페이지
  • 자사 공개 연구인 Clio와 계층적 요약으로 대량 대화 데이터에서 오용 패턴을 식별
  • 입력과 응답을 평가하는 분류기 운용
  • 네 사례 모두 관련 계정을 차단하고, 결과를 전반적 통제 체계에 반영
08 · 권고와 요청

평가 틀의 확장

  • 관계 형성과 공동체 편입을 중심으로 한 영향력 공작 평가 틀이 기존 Breakout Scale과 함께 필요 PDF p.3
  • 보안·안전 공동체와의 긴밀한 협력, 업계·정부·연구계의 공동 방어 강화 게시 페이지

10 · 요약자 주석

이 판본의 위치

요약자 주석
  • 시리즈의 출발점으로서 형식이 가장 가볍다. 네 사례 중 세 건이 "실제 피해 미확인"으로 끝나, 이후 판본과 비교할 때 피해 확인 수준이 중요한 비교축이 된다.
  • 영향력 공작을 "콘텐츠"가 아닌 "관계" 단위로 봐야 한다는 문제 제기는, 게시물 단위 허위정보 규율(삭제·표시 의무)이 이런 유형에 잘 맞지 않는다는 뜻으로 읽힌다.
  • 귀속을 확인하지 않았다고 명시한 점은 2025년 11월 판(고신뢰 국가 귀속), 2026년 9월 판(기업·기관 실명 특정)과 대비된다.
